SETUP:
1. Copy ForceSeatDI64.dll to "Assets\ForceSeatDI" directory
2. Open PrecisePos_Unity from Unity Editor
3. Load 'scene' from Scenes menu and hit the play button to see the demo
4. In contrast to other (CPP and CS) examples machine will not move itself after running Unity project. WSAD keys have to be used to control the machine
