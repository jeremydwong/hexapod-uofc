SETUP:
1. Open PrecisePos_Unreal.uproject in UE4 4.24
2. After project is launched "Binaries\Win64" directory will be created in project main directory
3. Copy ForceSeatDI64.dll to "Binaries\Win64" directory
4. You are ready to go!
